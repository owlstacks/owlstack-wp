# Synglify for WordPress

WordPress plugin for [Synglify](https://synglify.com).

Integrates `synglify/synglify-core` into WordPress sites — admin settings, post meta boxes, WP-Cron scheduling, REST API endpoints, and more.

## Status

Scaffolded — implementation pending.

## Planned Features

- Plugin bootstrap and WordPress hooks/filters
- Admin settings page
- Per-post publishing options (custom meta box)
- WP-Cron / Action Scheduler integration
- Custom database tables for delivery logs and credentials
- REST API endpoints for AJAX admin interactions

## Dependencies

- `synglify/synglify-core` (bundled via Composer)
